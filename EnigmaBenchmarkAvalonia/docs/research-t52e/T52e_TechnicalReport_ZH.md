## 摘要

西門子 & 哈斯克 T52e「Geheimschreiber」（秘密打字機）是二戰德軍戰略電傳密碼機家族最後一代，也是此系列中唯一在戰時未被破解的機型。有別於前代 T52a、b、c、d，T52e 透過 *Klartextfunktion*（KTF，明文相關步進）與 **H-繼電器** 混合層的結合，自 1943 年中以降抵擋瑞典密碼分析直至戰爭結束。儘管 T52e 在密碼學史上舉足輕重，學術與通俗文獻對其著墨有限；目前最具權威性的逆向工程文獻，是 Donald Davies 1982 年檢視倫敦科學博物館與慕尼黑兩台倖存機器後撰寫的內部技術備忘錄。

本報告以**位元精確的軟體模擬器所需之層級**重構 T52e，涵蓋完整金鑰流產生演算法，包括：

- 十個凸輪輪子的銷數與凸輪接點慣例；
- **H**、**SR** 繼電器網路的 XOR 拓撲，藉由直接判讀 Davies 論文 Figure 13–15 驗證，並以不變式 `SR1 ⊕ SR2 ⊕ … ⊕ SR10 = 0` 交叉核對；
- Figure 9 完整 32 列換位表，此表依 `(SR1..SR5)` 決定施加於 5 位元明文之置換；
- Figure 11 阻擋電磁鐵的步進邏輯（5 條方程式經直接追跡確認，另 5 條以電路對稱性推論）；
- 自 Davies Figure 11(a) 擷取可驗證之 24 週期測試向量。

我們另定義一個**縮減密鑰空間的 benchmark 攻擊**（2,400 萬候選），與已實作的 Lorenz SZ40 chi-only benchmark 可直接比對效能。

## 1. 歷史背景

T52 為德國二戰期間的**電傳打字機式**戰略密碼系統，地位相當於恩尼格瑪（Enigma，戰術前線密碼）與勞倫茲 SZ40/42 機（Lorenz，「Tunny」，德軍最高司令部密碼）之外的第三支柱。英方布萊切利園為此機取代號「Sturgeon（鱘魚）」。T52 由西門子 & 哈斯克自 1930 年代末開始生產，部署於能支撐這具笨重線上密碼附件的路線：固定的帝國郵政電路、強化指揮所、駐外大使館，以及高流量的軍級司令部。

共有五種型號：

| 型號  | 狀態                | 密碼分析結果                                         |
|-------|-------------------|-------------------------------------------------|
| T52a  | 早期 1932 年設計 | 1940 年 5 月由瑞典 Arne Beurling 僅以紙筆兩週內破譯 |
| T52b  | T52a 加射頻抑制  | 同 T52a                                        |
| T52c  | 改良步進         | 瑞典以機器輔助攻擊，1940–1943 間解密約 35 萬則訊息 |
| T52d  | 加入非線性輪步進 | 1942 年仍被瑞典人初步攻破                         |
| T52e  | 加入 H-繼電器混合與 KTF | **作戰中未被破解**；1943 年中流量驟減終結瑞典解譯期 |

英國布萊切利園首次攔截到 Sturgeon 流量是 1942 年夏季西西里–利比亞鏈路。Michael Crum 透過操作員重覆使用指示金鑰所產生的「深度（depth）」首次攻入。布萊切利對 Sturgeon 的攻擊從未像 Tunny 那樣持續——部分原因是 Sturgeon 是三大德軍主要密碼系統中數學上最複雜者，部分因為德國空軍幾乎普遍將戰略 Sturgeon 訊息重傳於較易攻擊的低階密碼。

戰後機器四散。其中兩台倖存，於 1978 年由英國國家物理實驗室（NPL）Donald Davies 重新檢視，並撰寫了作為本報告**主要依據**的技術備忘錄。

## 2. 物理構造

### 2.1 機械佈局

T52e 外觀類似一台笨重的電傳打字機：約 60 公斤，裝於桌面大小機殼，整合鍵盤、印字機、紙帶打孔機、以及密碼單元本身。密碼單元由以下構件組成：

- **十個凸輪輪子**，分布於發送、接收、翻譯/列印三根凸輪軸，銷數為 47、53、59、61、64、65、67、69、71、73，**兩兩互質**，乘積 8.94 × 10¹⁷ 即任一輪子狀態完全重複前所需週期數。
- **每輪兩個凸輪接點**，分別標示為 A 與 B。二者讀取*同一*銷圖樣，但在凸輪圓周上相差約 1/3 圈。**A 接點**驅動步進邏輯、**B 接點**驅動金鑰流產生邏輯。
- **十組金鑰設定開關**（A…K），每組 10 個位置（`1, 3, 5, 7, 9, I, II, III, IV, V`）。這些開關構成 10 個 B 通道到 10 個內部 X 通道的置換。
- **H/SR 繼電器箱**，形成兩層 XOR 混合樹，將十條 X 訊號轉換為十條 SR 訊號。SR1…SR5 驅動位元置換網路；SR6…SR10 對明文位元執行 Vernam XOR。
- **阻擋電磁鐵邏輯箱**，含十個 M 電磁鐵（M1..M10），以繼電器梯形網路連接至 A 接點。步進週期時若某 M 被激發，對應輪子被阻擋不動；否則輪子前進一銷。
- **KTF 開關**（Klartextfunktion，「明文函數」），一小面板，將**前一字元明文的第 3 位元**饋入 M1、M8、M9、M10 的步進邏輯。KTF 關閉時機器為自主（步進僅依賴輪子狀態）；KTF 開啟時金鑰流成為明文相關，密碼變為非線性——這是作戰上最重要的防禦特徵。

### 2.2 時序

T52e 同步電傳打字機，50 baud 速率——每 5 位元 ITA2 字元佔用 20 毫秒。每字元時槽含三階段：

1. **發/收階段**（主要 20 毫秒）。輪子靜止，B 接點提供當前金鑰流。5 個明文位元通過 H/SR 網路一次，每字元。
2. **撥爪驅動階段**（下一時槽開始）。由 A 接點狀態設定阻擋器，撥爪驅動機構嘗試前進每個輪子。被對應 M 激發的輪子保持不動，其餘前進一銷。
3. **翻譯/列印階段**。若機器為接收端，解密字元鎖存入列印繼電器 R1..R5。

T52e 啟用 KTF 時，繼電器 **RR3** 跨字元邊界從 R3 奴隸複製，使週期 *n* 中 M1、M8、M9、M10 的步進取決於明文字元 *n − 1* 的第 3 位元。這是**此密碼最關鍵的防禦機制**。

## 3. 數學規格

### 3.1 符號

令 `Xᵢ`（i = 1..10）代表金鑰設定開關後十條內部金鑰流線。`Hᵢ` 與 `SRᵢ` 為中繼電器網路中繼與最終輸出。`Sᵢ`（i = 1..5）為一 Baudot 字元的五個明文位元，`Cᵢ` 為五個密文位元。`Aᵢ` 為輪 *i* 之 A 接點狀態，`Mᵢ` 為阻擋電磁鐵 *i* 之狀態。

所有訊號為二元。XOR 記作 `⊕`；AND 記作 `∧`；NOT 記作 `¬`。

### 3.2 H 繼電器網路（Davies Fig 14，已驗證）

```
H1  = X1 ⊕ X2        H6  = X1 ⊕ X6
H2  = X3 ⊕ X4        H7  = X2 ⊕ X7
H3  = X5 ⊕ X6        H8  = X3 ⊕ X8
H4  = X7 ⊕ X8        H9  = X4 ⊕ X9
H5  = X9 ⊕ X10       H10 = X5 ⊕ X10
```

前五個 H 繼電器配對相鄰通道（1-2, 3-4, …, 9-10）；後五個配對間隔五格的通道（1-6, 2-7, …, 5-10）。**每個 X 恰出現於兩條 H 方程式**。

### 3.3 SR 繼電器網路（Davies Figs 13–14，已驗證）

```
SR1 = H1 ⊕ H8        SR6  = H3 ⊕ H7
SR2 = H6 ⊕ H7        SR7  = H2 ⊕ H5
SR3 = H3 ⊕ H8        SR8  = H1 ⊕ H9
SR4 = H2 ⊕ H10       SR9  = H5 ⊕ H6
SR5 = H4 ⊕ H10       SR10 = H4 ⊕ H9
```

代入 H 方程式可將每個 SR 展開為四條 X 的 XOR：

```
SR1  = X1 ⊕ X2 ⊕ X3 ⊕ X8
SR2  = X1 ⊕ X2 ⊕ X6 ⊕ X7
SR3  = X3 ⊕ X5 ⊕ X6 ⊕ X8
SR4  = X3 ⊕ X4 ⊕ X5 ⊕ X10
SR5  = X5 ⊕ X7 ⊕ X8 ⊕ X10
SR6  = X2 ⊕ X5 ⊕ X6 ⊕ X7
SR7  = X3 ⊕ X4 ⊕ X9 ⊕ X10
SR8  = X1 ⊕ X2 ⊕ X4 ⊕ X9
SR9  = X1 ⊕ X6 ⊕ X9 ⊕ X10
SR10 = X4 ⊕ X7 ⊕ X8 ⊕ X9
```

**不變式**：每個 `Xᵢ` 恰出現於四條 SR 方程式，因此所有十個 SR 位元模 2 和為零：

```
SR1 ⊕ SR2 ⊕ SR3 ⊕ SR4 ⊕ SR5 ⊕ SR6 ⊕ SR7 ⊕ SR8 ⊕ SR9 ⊕ SR10  =  0
```

Davies 稱此為「SR1–10 之間獨立線性關係」。密碼分析上，此式將 10 維 SR 空間降為 9 維仿射子空間。

### 3.4 加密動作（Davies Figs 5, 7, 9）

對單一字元：

1. **Vernam 階段**。五個明文位元與 SR6..SR10 做 XOR：

   ```
   Tᵢ = Sᵢ ⊕ SR(5+i)        i = 1..5
   ```

2. **換位階段**。位元組 `T = (T1, T2, T3, T4, T5)` 由 σ(SR1,…,SR5) 置換，σ 為由 SR1–SR5 四位元圖樣選出之 32 個 5 元素置換之一：

   ```
   Cᵢ = T[σ_{SR1..SR5}(i)]    i = 1..5
   ```

以下 **Table 1** 為 Davies 論文 Figure 9 完整 32 列置換表，經直接判讀驗證。當 SR1..SR5 全部激發時置換為**恆等**——此為主控制開關置於「clear」（明碼）位置所得條件。

**Table 1. Davies Figure 9 轉錄**。列索引為 `SR1 + 2·SR2 + 4·SR3 + 8·SR4 + 16·SR5` 加一。`σ(i)` 為密文位置 `i` 所呈現之明文元素索引。

表中 32 條項目含有重複置換。例如第 1 列 `(SR=00000)` 與第 18 列 `(SR=10001)` 皆產生置換 `(1,3,4,5,2)`；第 2 列與第 17 列皆產生 `(2,3,4,5,1)`。Davies 指出「T52e 以 5 個換位通道實作時，並未使用完整置換集合」——實際 T52e 僅實現 120 個可能置換中大約二十餘個相異者。

**互逆性**。表中每個置換若非對合，便與表中另一列之逆在同一表中成對出現——這正是同一電路可同時加密與解密的根本原因。

### 3.5 步進邏輯（Davies Fig 11）

十個 A 接點驅動一座繼電器梯形網路，其十個輸出為 M 電磁鐵電流。每個撥爪驅動週期：

- 若 `Mᵢ = 1`，輪 *i* 被阻擋不動；
- 若 `Mᵢ = 0`，輪 *i* 前進一銷。

**已確認方程式**（由 Figure 11 上半「Without KTF」直接追跡）：

```
M3 = ¬A2 ∧  A1
M4 =  A2 ∧  A3                （Davies 第 12 頁內文明確給出）
M5 = ¬A4 ∧ ¬A3
M6 =  A4 ∧  A5
```

**推論方程式**（以 A6/A8/A10 上層樹電路對稱性推論；正式發表前須比對 Figure 11(a) 測試向量驗證）：

```
M2  = ¬A10 ∧ ¬A1
M7  =  A10 ∧ ¬A6 ∧ ¬A9
M8  =  A10 ∧ ¬A6 ∧  A9
M1  =  A10 ∧  A6 ∧ ¬A8
M10 =  A10 ∧  A6 ∧  A8 ∧ ¬A7
M9  =  A10 ∧  A6 ∧  A8 ∧  A7
```

**啟用 KTF 時**，受 `RR3 = R3(前一字元)` 影響的四個電磁鐵：

```
M1, M8, M9, M10 — 結構同上，但在 Davies Figure 11 下半對應位置額外 AND
                  上 RR3 或 ¬RR3。
```

### 3.6 測試向量（Davies Figure 11(a)）

慕尼黑機器自全 1 初始位置（所有輪子銷位置 = 1）、KTF 關閉、執行 24 撥爪驅動週期後，十個輪子到達之銷位置：

```
W1=20, W2=22, W3=20, W4=16, W5=23, W6=16, W7=17, W8=14, W9=17, W10=14
```

Davies Figure 11(a) 另印出完整 24 週期內每個 M 與 A 接點之波形。宣稱歷史精確重現之實作必須**逐位元**重現這些波形——此為任何 T52e 軟體模擬器最重要之驗證目標。

## 4. 密碼強度

### 4.1 密鑰空間

每日金鑰由以下組成：

- 十個凸輪的銷圖樣——總計 47 + 53 + 59 + 61 + 64 + 65 + 67 + 69 + 71 + 73 = **629 位元**，通常每週或每月固定並獨立分發；
- 十個金鑰設定開關位置——10¹⁰ 個排列，但只有「合法」雙射設定有意義，該數為 10! = 3.6 × 10⁶；
- 十個輪子起始位置——47·53·…·73 ≈ **8.94 × 10¹⁷**；
- KTF 開/關——1 位元。

粗略估計每日密鑰空間約 10²⁴，即便今日任何暴力破解亦無力應對。

### 4.2 歷史破譯

- **1940 年 5 月**——瑞典 FRA Arne Beurling 以紙筆分析柏林–奧斯陸帝國郵政線上之深度對，破解 T52a。這被公認為二戰最偉大的密碼分析成就之一。
- **1940 – 1943**——Ericsson 建造 T52 類比機（「Apparaten」），利用操作員失誤造成之深度與 T52a/b/c 的線性金鑰流，可能解讀了約 35 萬則德國訊息。
- **1943 年中**——德國導入 T52e。瑞典解密數降至零：KTF 回饋使深度對齊變得含糊，且德軍同時加強操作紀律。
- **1942 年起**——布萊切利園 Testery 組偶爾在德國空軍操作員同一金鑰發三則以上訊息時破入 Sturgeon。攻擊無法規模化，最終放棄以集中攻 Tunny——後者正是德國空軍喜歡將大量 Sturgeon 訊息重傳的對象。

非線性步進（A→M 回饋）加上金鑰流混合（H/SR 層）的組合，讓 T52e **在作戰實務上達到實用安全等級**。若德國空軍執行每訊息獨立指示碼並抑制重傳，布萊切利能看到的流量將非常有限。

### 4.3 縮減密鑰空間 benchmark

完整暴力破解 T52e 輪子起始位置空間（8.94 × 10¹⁷）於本世紀任何已知裝置上皆不可行。本 benchmark 參考布萊切利 Testery 組歷史作法：**假設其中 6 個輪子的起始位置已由其他方法（深度、明文片段、解析復原）求得，僅對其餘 4 個輪子暴力搜尋**。

若未知四輪為 W7…W10（銷數 67、69、71、73），殘餘密鑰空間：

```
67 × 69 × 71 × 73 = 23,951,289 ≈ 2,400 萬候選
```

此數字與姊妹 benchmark 中 Lorenz SZ40 χ1×χ2 搜尋的 2,200 萬候選相當，使不同後端（Scalar / SIMD / GPU）間的效能比較直接有意義。

**每候選作業**。產生 10 條輪子 B 接點流；通過當日金鑰開關置換得 X；經 H、SR XOR 運算得 10 條 SR 訊號；對每個密文字元按該字元 SR1-SR5 圖樣反轉 Figure 9 換位；XOR 扣除 SR6..SR10 得候選明文；以 Baudot 重合指數評分。德文明文期望 IC ≈ 0.085，隨機分布 IC ≈ 0.031——四比一對比在幾百字元密文上即易分辨。

## 5. 研究方法

研究分四階段進行：

1. **文獻掃描**。T52e 英文資料稀少。我們查閱 Crypto Museum、Jörgen Nilsson 相關網頁、Wikipedia 條目、Frode Weierud 的 CryptoCellar 模擬器說明、Gannon《Colossus: Bletchley Park's Greatest Secret》（2006）。**沒有任何一種公開來源提供內部邏輯**，全數皆指向同一權威：Donald Davies 1982 技術備忘錄。

2. **一手來源取得**。Crypto Museum 提供 Davies 論文掃描 PDF。我們以 `curl` 下載（此專案其他部份使用的 Playwright 下載器在面對 Crypto Museum Cloudflare 層處理二進檔案時失效）。pdftotext 可清潔擷取敘述文字，但**所有表格式圖示全部毀損**；數值表僅存於掃描圖內。

3. **逐圖驗證**。每個圖示處理流程：
   1. 以 PyMuPDF 在 170 DPI 渲染相關 PDF 頁面，調整旋轉使圖示正向橫排可讀。
   2. 裁剪並於最高 240 DPI 重渲染，使單元格數字達可讀解析度。
   3. 將圖示內容以文字形式轉錄。
   4. **轉錄完成後立即刪除中間 PNG**（為遵守對話 2000 像素影像預算，不得不然）。

   研究初期曾嘗試詢問 Google Gemini 以快速取得 H/SR 拓撲，Gemini 回覆了一個 **語氣自信但可證明錯誤** 的圖樣。Davies 的圖示顯示 `H1 = X1 ⊕ X2`，而 Gemini 給 `H1 = X1 ⊕ X6`。Gemini 的答案具有數學上的優雅性，但與實際物理佈線無關。**§3 中每條方程式因此均由圖示直接重新判讀驗證**。

4. **自洽檢查**。我們從擷取方程式計算 `SR1 ⊕ … ⊕ SR10`，確認其恆為零，與 Davies「獨立線性關係」之陳述吻合。驗證 Figure 9 置換表時，確認全 32 列每列皆為 {1,2,3,4,5} 之有效置換，且第 32 列（所有 SR 激發）確為恆等，完全符合論文文字要求。

阻擋邏輯中有四條方程式可直接由 Figure 11 上層樹讀出；其餘六條涉及三層深度之繼電器樹，其箭頭慣例在掃描版上無法明確辨識。本報告將此六條標示為**推論（inferred）**（§3.5），並建議任何宣稱位元精確之歷史重現實作，在正式發表前應以 Figure 11(a) 波形軌跡進行經驗性驗證。

## 6. 軟體模擬實作建議

- **狀態**：每個輪子需要銷圖樣位元陣列（長度等於銷數）、當前銷位置、A 與 B 接點推導值（B 接點即 A 凸輪偏移約 1/3 圈，易用同一位元陣列之偏移索引實作）。
- **每字元熱迴圈**：  
  ```
  for each of 10 wheels i:
      A[i] = pins[i][ (angle[i] + A_offset[i]) % pin_count[i] ]
      B[i] = pins[i][ (angle[i] + B_offset[i]) % pin_count[i] ]
  X = switch_permutation(B)                      // 10 × 10 置換
  compute H, SR from X via table 3.2, 3.3        // 20 次 XOR
  T = plaintext ⊕ (SR6..SR10)                    // 5 次 XOR
  cipher = perm_table[ SR1..SR5 ](T)             // 32 選 1 表查
  ```
- **步進迴圈**（每字元一次，於加密之後）：  
  ```
  compute M1..M10 from A1..A10 via §3.5 equations
  for each wheel i where M[i] == 0:
      angle[i] = (angle[i] + 1) % pin_count[i]
  ```
- **Shader 友善佈局**：若將銷數統一為 8 位元，十個輪子角度可打包入單個 `uvec4`（剩兩個 lane 備用）；SR = XOR-4-of-10 方程式可打包為每 SR 四個 10 位元遮罩，在單條 shader 指令內以 popcount-XOR 完成。32 列置換表可每列打包為五個 3 位元欄位（共 15 位元），存於單個 `uvec4`。

以上觀察直接驅動本專案中 Enigma 與 Lorenz 問題 Scalar / SIMD / GPU-shader 三後端的設計。

## 7. 待解問題

1. **六條推論 M 方程式**。我們從 Figure 11 直接擷取 5 條方程式，另 5 條以對稱性推論。有興趣的讀者若能取得原始文件（或接觸慕尼黑倖存機器），應以 Figure 11(a) 波形驗證此六條方程式，方可宣稱「位元精確」。

2. **慕尼黑凸輪銷圖樣（Figure 3）**。本報告未將 629 個銷位置逐一轉錄。**就密碼學研究而言此事無關緊要**——任何自洽銷圖樣均會以完全相同方式運用演算法。但若為*歷史*研究、欲匹配戰時實際解密結果，則 Figure 3 必須擷取。

3. **KTF 接線歷史**。KTF 開關的重佈線歷史本身即是密碼分析線索——慕尼黑機器顯示 KTF 佈線於 T52e 服役期間至少變更過一次。有可能某戰爭末期變體**無法**以 Davies 重現之早期變體所適用之攻擊法破譯。

4. **T52c 與 T52e 內部差異**。T52c/d 直接將 X 通道用作金鑰流；T52e 的 H 繼電器介入層是防禦上的關鍵變革。Davies 指出由 T52e 佈線刪除 H 層即可輕易得出 T52c 模擬器佈線；本報告未驗證此說法，T52c 變體不在本 benchmark 範圍內。
