--------------------------------------------------------
二戰德軍 Enigma 明文格式慣例（本訊息所遵守）
--------------------------------------------------------

1. 只允許 A-Z 共 26 個拉丁字母（Enigma 轉子也只處理這 26 個）
2. 德文變音轉寫：
   Ä → AE    （本訊息：AENDERN = Ändern 改變）
   Ö → OE    （本訊息：ZERSTOERER = Zerstörer 驅逐艦）
   Ü → UE    （本訊息：UEBERSCHWERE = überschwere 超重；FUEHRUNG = Führung 指揮）
   ß → SS    （本訊息：DREIUNDDREISSIG = 33）
3. 數字拼寫成德文（0-9 → NULL/EINS/ZWEI/DREI/VIER/FUENF/SECHS/SIEBEN/ACHT/NEUN）：
   本訊息範例：
     NEUNUNDZWANZIG   = 29
     DREIUNDDREISSIG  = 33
     VIERUNDZWANZIG   = 24
     EINUNDZWANZIG    = 21
     SECHZEHN         = 16
4. 標點：
   句點（.） → X
   逗號（,） → Y 或 ZZ（單位而異）
   分段      → STOP（明文詞，不是真分段符）
