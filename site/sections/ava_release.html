🚀 aprnesava 跨平台 preview — Windows / Linux / macOS

提供 Linux x86_64 / Linux ARM64 / macOS ARM64 三個平台的 self-contained 執行檔，與既有 Windows x64 並列。Windows 沿用 Win32 WaveOut + DirectInput8/XInput；Linux/macOS 走 Hexa.NET.MiniAudio（音訊）+ Hexa.NET.SDL3（手把）NuGet 套件，prebuilt native binary 已內建在壓縮檔中。本版另回補 xBRZ 濾鏡修正（消除角落混合假藍點、跨幀殘留、右緣漏混合）。模擬精度仍是 blargg 184/184 + AccuracyCoin 139/139 雙滿分。

🌐
跨平台四種 RID
win-x64 / linux-x64 / linux-arm64 / osx-arm64 四份 archive 各自 self-contained，目標機器免裝任何相依（含 .NET runtime）。
⚡
GPU 加速 CRT
SkSL shader 跑在 D3D11/Metal/OpenGL，全程不回 CPU。10× scale 實測比 CPU 後端快 2.5×（58.67 vs 23.45 FPS）。
🎯
HD_NTSC 12× Fsc
2048 sample/scanline（NetFx 是 1024）。RF 模式 herringbone、color fringing、chroma blur 還原更接近真實 NTSC 訊號。
