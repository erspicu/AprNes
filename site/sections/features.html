核心特色

從硬體文件出發，逐一實作每個 NES 子系統的精確行為

⏱️
Cycle-Accurate 時序

CPU、PPU、APU 全部以 per-cycle 精度模擬。每次記憶體存取觸發精確的 tick 計時，NMI/IRQ 延遲、DMA 週期偷取等細節均符合真實硬體行為。

🔀
完整 DMA 模擬

OAM DMA 514 cycle、DMC 週期偷取（3–4 cycle）、phantom read、implicit abort 等所有 DMA 時序邊界情況均正確實作，通過最嚴苛的 DMA 測試 ROM。

🎵
APU 五聲道音效

Pulse×2、Triangle、Noise、DMC 完整實作。自製 WaveOut 輸出（winmm.dll），44100Hz 16-bit，無任何第三方音效套件依賴。

🤖
AI 協作開發

以 AI 輔助研究 NES 硬體行為、分析測試 ROM 失敗原因、設計修復方案、效能最佳化。探索 AI-driven 嵌入式系統模擬開發的可行邊界。

🧪
自動化測試流程

184 個 blargg test ROM + 138 個 AccuracyCoin 測試全自動化。截圖比對、CRC 驗證、headless 批次執行，每次 commit 均有正確性保障。

🗺️
多 Mapper 支援

65 個 Mapper 已實作，61 個人工校驗通過。涵蓋 MMC1/MMC3/MMC5/VRC6/VRC7/FME-7/Namco 163/FDS 等，支援擴充音效。

🖼️
畫面 Scaler Filter

xBRZ 2x/4x/6x 高品質影像放大濾鏡，多核心平行加速。內建 NTSC CRT 比例修正與 YIQ color bleeding 模擬效果。

📺
NTSC 類比訊號模擬

物理建模的 NTSC 複合視訊訊號：Level 2 快速 IIR 路徑或 Level 3 UltraAnalog 21.477 MHz 時域波形解調。RF / AV / S-Video 三種端子參數，搭配 CRT 電子束光學模擬。

🎧
AudioPlus DSP 音效引擎

三種音效模式：Raw（原始）、Classic（經典濾波）、Modern Digital（現代 DSP）。Mode 2 處理鏈：DC Blocker → FIR LPF → Stereo Widener → Comb Reverb → Biquad HPF → Soft Limiter。支援擴充音效晶片（VRC6/VRC7/5B/N163/FDS）獨立混音。
