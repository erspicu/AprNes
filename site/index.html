AprNes

C# 實作的任天堂紅白機模擬器，以 cycle-accurate 精準度為目標，通過業界最嚴格的測試驗證， 並運用 AI 協作持續演進。

專案狀態

本專案已達成里程碑目標。未來開發將在以 .NET 10 + Avalonia 為基礎的新專案中繼續進行，擺脫 .NET Framework 4.8.1 的歷史包袱。遷移完成後，本倉庫將不再積極維護。

本專案由 AI 輔助開發，著重於利用現代運算能力探索並實現作者想嘗試的概念。

核心特色

從硬體文件出發，逐一實作每個 NES 子系統的精確行為

⏱️
Cycle-Accurate 時序

CPU、PPU、APU 全部以 per-cycle 精度模擬。每次記憶體存取觸發精確的 tick 計時，NMI/IRQ 延遲、DMA 週期偷取等細節均符合真實硬體行為。

🔀
完整 DMA 模擬

OAM DMA 514 cycle、DMC 週期偷取（3–4 cycle）、phantom read、implicit abort 等所有 DMA 時序邊界情況均正確實作，通過最嚴苛的 DMA 測試 ROM。

🎵
APU 五聲道音效

Pulse×2、Triangle、Noise、DMC 完整實作。自製 WaveOut 輸出（winmm.dll），44100Hz 16-bit，無任何第三方音效套件依賴。

🤖
AI 協作開發

以 AI 輔助研究 NES 硬體行為、分析測試 ROM 失敗原因、設計修復方案、效能最佳化。探索 AI-driven 嵌入式系統模擬開發的可行邊界。

🧪
自動化測試流程

184 個 blargg test ROM + 138 個 AccuracyCoin 測試全自動化。截圖比對、CRC 驗證、headless 批次執行，每次 commit 均有正確性保障。

🗺️
多 Mapper 支援

65 個 Mapper 已實作，61 個人工校驗通過。涵蓋 MMC1/MMC3/MMC5/VRC6/VRC7/FME-7/Namco 163/FDS 等，支援擴充音效。

🖼️
畫面 Scaler Filter

xBRZ 2x/4x/6x 高品質影像放大濾鏡，多核心平行加速。內建 NTSC CRT 比例修正與 YIQ color bleeding 模擬效果。

📺
NTSC 類比訊號模擬

物理建模的 NTSC 複合視訊訊號：Level 2 快速 IIR 路徑或 Level 3 UltraAnalog 21.477 MHz 時域波形解調。RF / AV / S-Video 三種端子參數，搭配 CRT 電子束光學模擬。

🎧
AudioPlus DSP 音效引擎

三種音效模式：Raw（原始）、Classic（經典濾波）、Modern Digital（現代 DSP）。Mode 2 處理鏈：DC Blocker → FIR LPF → Stereo Widener → Comb Reverb → Biquad HPF → Soft Limiter。支援擴充音效晶片（VRC6/VRC7/5B/N163/FDS）獨立混音。

📺 NTSC 類比訊號模擬

物理建模的複合視訊訊號管線，還原 CRT 電視的真實觀感

從電子訊號到 CRT 掃描線，逐步還原真實畫面

AprNes 的類比模擬直接對 NES PPU 輸出的原始調色盤索引進行 NTSC 複合視訊編解碼： 以 4 samples/dot（21.477 MHz）建立複合訊號，再經 YIQ 解調、Gamma 編碼輸出至縮放後的緩衝區。 選擇性開啟 CRT Stage 2，加入高斯掃描線 Bloom 與 BrightnessBoost，精確模擬 CRT 電視的光學特性。

📡 RF 射頻 🔌 AV 複合 🎛️ S-Video 📺 CRT Bloom ⚡ SIMD 加速 🎨 8:7 AR
S(t) = Y(t) + I(t)·cos(2π·fsc·t) − Q(t)·sin(2π·fsc·t)
fsc = 3.579545 MHz  |  4 samples/dot  |  21.477 MHz
NTSC 複合訊號方程式（Level 3 UltraAnalog 完整實作）
LEVEL 2 — Fast Analog
快速 IIR 路徑

不生成完整的 21.477 MHz 時域波形，直接以預算 YIQ LUT（64 色 × 6 相位）搭配 IIR SlewRate / ChromaBlur 濾波器近似複合視訊色彩擴散， 以極低的運算量提供自然的 dot crawl 與色彩暈染效果。

  • 64 色 × 6 相位 YIQ LUT（Phase C 優化）
  • IIR SlewRate（模擬電容響應）+ ChromaBlur
  • RF / AV / S-Video 三種端子參數獨立可調
  • SIMD AnalogSize 2x / 4x / 6x / 8x 輸出
LEVEL 3 — UltraAnalog ✦
物理正確波形解調

完整模擬 NES PPU 輸出的 21.477 MHz NTSC 複合波形，並以 Hann 視窗 FIR 相干解調（Y 6-tap / I 18-tap / Q 54-tap）， 還原真實電視接收到的帶限 YIQ 訊號，色彩精度與真實硬體一致。

  • 21.477 MHz 時域複合波形生成（cosTab6/sinTab6 LUT）
  • Hann 窗 FIR 相干解調 Y/I/Q（帶限精確）
  • RF AM 調變/解調 + 音訊載波 buzz bar 干擾
  • SIMD 批次 YIQ→RGB 轉換（二次 Gamma 取代 LUT）
  • 接續 CRT Stage 2（高斯掃描線 Bloom）
STAGE 2 — CRT Optics
CRT 電子束光學模擬

UltraAnalog 開啟時，linearBuffer（1024×240 線性 RGB）經高斯掃描線 Bloom 垂直擴展至 256N×210N， 模擬 CRT 電子束的物理擴散、高光溢出與亮度補償。

  • 高斯權重掃描線（BeamSigma 可調）
  • Bloom 高光溢出（BloomStrength）
  • BrightnessBoost 黑溝亮度補償
  • RF / AV / S-Video 三組獨立參數
訊號處理管線
PPU 調色盤索引 → NTSC 複合訊號 → YIQ 解調 → sRGB Gamma → AnalogScreenBuf
↑ Stage 1（Ntsc.cs）
＋ Stage 2 CrtScreen（UltraAnalog）

🎧 AudioPlus DSP 音效引擎

三段式音效處理管線，從原始硬體音色到現代數位音場

從 NES 原始波形到沉浸式音場，逐級提升聽感

AudioPlus 提供三種音效模式，讓使用者自由選擇聽感風格。Mode 0 輸出 APU 原始混音， Mode 1 套用 NES 硬體等效濾波器（HPF 440 Hz + LPF 14 kHz），Mode 2 加入完整 DSP 處理鏈， 提供立體聲空間感、殘響深度與動態限幅，同時保留 NES 音色的本質特徵。

🔇 Mode 0 Raw 🎛️ Mode 1 Classic 🎧 Mode 2 Modern 🎹 擴充音效 🎚️ 獨立音量
APU out → DC Block → FIR LPF → Stereo → Reverb → HPF → Limiter
44100 Hz · 16-bit · per-sample processing
Mode 2 Modern Digital DSP 處理鏈
MODE 0 — Raw
原始輸出

直接輸出 APU 混音結果，不經過任何濾波處理。適合需要精確分析原始波形的開發者與研究用途。

  • 無濾波、無處理
  • 最低延遲
  • 適合波形分析
MODE 1 — Classic
經典硬體濾波

模擬 NES 主機的硬體音效特性：440 Hz 高通濾波器去除直流偏移與低頻隆隆聲，14 kHz 低通濾波器柔化高頻毛刺，還原真實主機的聽感。

  • 440 Hz 一階高通濾波器
  • 14 kHz 一階低通濾波器
  • 忠實還原硬體音色
MODE 2 — Modern Digital ✦
現代數位音效

完整 DSP 處理鏈，在保留 NES 音色特徵的同時提供現代化的聽覺體驗。Stereo Widener 營造空間感，Comb Reverb 增添深度，Soft Limiter 防止削波失真。

  • DC Blocker 直流阻隔
  • FIR 低通濾波器（高頻抑制）
  • Stereo Widener 立體聲展寬
  • Comb Reverb 梳狀殘響
  • Biquad HPF + Soft Limiter
EXPANSION AUDIO
擴充音效晶片支援

卡帶擴充音效晶片的輸出經過獨立的混音通道處理，與主 APU 分離混音後再匯入 DSP 鏈，確保擴充音效的音量平衡與音色品質。

  • VRC6 — 2 Pulse + Sawtooth
  • VRC7 — OPLL FM 合成（6 聲道）
  • Sunsoft 5B — 3 聲道方波（PSG）
  • Namco 163 — 8 聲道波表
  • FDS — 波表 + FM 調變
音效處理管線
APU 5ch 混音 → DC Blocker → FIR LPF → Stereo Widener → Comb Reverb → Biquad HPF → Soft Limiter
↑ Mode 2 Modern Digital 完整處理鏈
+ Expansion Audio (VRC6/VRC7/5B/N163/FDS → 獨立混音通道)
效能特性
  • FIR 展開最佳化 + Transposed Biquad，吞吐量 +20–28%
  • Flat architecture — 無虛擬函式、無 heap 配置
  • 每聲道獨立音量控制（Pulse 1/2, Triangle, Noise, DMC）

TriCNES 時序架構移植

移植高精度時序模型，達成雙滿分精準度

AprNes 移植了 TriCNES 的時序架構，以達成更高的模擬精準度。TriCNES 是一款專注於學術研究與 TAS 正確性的優秀模擬器，其設計方向朝著真實電路層級的行為模擬前進。感謝 TriCNES 作者的傑出工作。

移植的動機來自於在 scanline-a1、colorwin_ntsc 等測試 ROM 中發現的 PPU 渲染不精確問題。原有的時序模型無法正確處理這些邊界情況，而 TriCNES 的高精度時序架構能夠精確重現真實硬體行為。

移植完成後，AprNes 達成 blargg 184/184 + AccuracyCoin 138/138 雙滿分（Commit 03385dd）。高精度時序模型帶來額外的運算成本，效能最佳化持續進行中。
