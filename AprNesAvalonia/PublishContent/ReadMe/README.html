AprNes

A cycle-accurate NES emulator / Cycle-accurate NES 模擬器

About This Project

AprNes is a cycle-accurate NES (Nintendo Entertainment System) emulator written in C#. It achieves perfect scores on both the blargg (174/174) and AccuracyCoin (136/136) test suites.

This project was developed with AI assistance (GitHub Copilot / Claude), with a focus on leveraging modern computing power to explore and implement concepts the author wanted to try.
