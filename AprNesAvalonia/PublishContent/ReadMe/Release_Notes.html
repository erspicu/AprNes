2026-03-26 ~ 2026-03-28

NEW AudioPlus DSP Engine

  • Three audio modes: Raw (Mode 0), Classic (Mode 1), Modern Digital (Mode 2)
  • Mode 2 DSP chain: DC Blocker → FIR LPF → Stereo Widener → Comb Reverb → Biquad HPF → Soft Limiter
  • Per-channel processing for expansion audio (VRC6, VRC7, 5B, N163, FDS)
  • Performance: +20~28% throughput via FIR unroll, transposed biquad, flat architecture

NEW Famicom Disk System (FDS) Support

  • BIOS validation with SHA-256 verification
  • Disk I/O state machine: motor control, head delay, per-byte transfer, CRC-16
  • Dual IRQ sources: timer IRQ + disk transfer IRQ
  • FDS wavetable audio with FM modulation
  • Automatic disk side swapping via BIOS routine detection
  • Verified: 10+ titles (Donkey Kong, Super Mario Bros., Dracula II, etc.)

  • Others: Irem H-3001, Taito X1-005/X1-017, GxROM, Mapper 070/071/089/152/206 — mirroring & banking fixes

PERF NTSC / CRT Post-Processing Optimization

  • Symmetric I/Q demodulation mode, Q FIR dual-accumulator SIMD
