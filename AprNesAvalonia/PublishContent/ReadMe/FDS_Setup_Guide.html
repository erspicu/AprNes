AprNes — FDS Setup Guide

Play Famicom Disk System games / 遊玩 Famicom Disk System 磁碟機遊戲

1 What is FDS?

The Famicom Disk System (FDS) was an add-on for the Japanese Famicom (NES) that used rewritable floppy disks instead of cartridges. Many classic titles were released exclusively on FDS, including early versions of The Legend of Zelda, Metroid, Kid Icarus, and Castlevania.

FDS games require a BIOS ROM to boot — this BIOS was built into the original hardware. AprNes needs a copy of this BIOS file to emulate FDS games.

2 Obtain the FDS BIOS

You need the official Nintendo FDS BIOS file, commonly known as disksys.rom.

PropertyValue
File nameDISKSYS.ROM
File size8,192 bytes (8 KB)
SHA-25699c18490ed9002d9c6d999b9d8d15be5c051bdfa7cc7e73318053c9a994b0178
Legal notice

The FDS BIOS is copyrighted by Nintendo. You should only use a BIOS dump from hardware you own. AprNes does not include this file.

3 Place the BIOS file

Create a folder named FDSBIOS in the same directory as AprNes.exe, and place the BIOS file inside:

<AprNes.exe location>\FDSBIOS\DISKSYS.ROM

For example:

C:\Games\AprNes\AprNes.exe
C:\Games\AprNes\FDSBIOS\DISKSYS.ROM
Important

The file must be named exactly DISKSYS.ROM (case-insensitive on Windows). The folder must be named exactly FDSBIOS.

4 Load an FDS game

Open AprNes and load an FDS ROM file (typically .fds extension) the same way you would load a regular NES ROM. AprNes automatically detects FDS format and loads the BIOS.

Supported FDS file formats:

  • With header — Files starting with FDS\x1A (the standard .fds format)
  • Headerless (raw) — Raw disk images where file size is a multiple of 65,500 bytes
Disk swapping

For multi-disk games, AprNes handles disk side switching automatically. When the game prompts you to flip or swap the disk, the emulator detects the request via the BIOS and inserts the correct disk side.

5 Verification

Your final folder structure should look like this:

AprNes.exe
configure\
FDSBIOS\
  └── DISKSYS.ROM (8,192 bytes)
tools\
... (other files)

If the BIOS file is missing or invalid, AprNes will display an error message when you try to load an FDS game, indicating what went wrong (file not found, wrong size, etc.).

1 什麼是 FDS？

Famicom Disk System（FDS）是日本 Famicom（紅白機）的磁碟機擴充周邊，使用可讀寫的軟碟取代卡匣。許多經典遊戲最初都是以 FDS 格式獨佔發行，包括早期版本的薩爾達傳說、銀河戰士、光神話和惡魔城等。

FDS 遊戲需要一份BIOS ROM才能啟動——這個 BIOS 內建於原始硬體中。AprNes 需要這份 BIOS 檔案才能模擬 FDS 遊戲。

2 取得 FDS BIOS

您需要任天堂官方的 FDS BIOS 檔案，通常稱為 disksys.rom。

屬性值
檔案名稱DISKSYS.ROM
檔案大小8,192 bytes（8 KB）
SHA-25699c18490ed9002d9c6d999b9d8d15be5c051bdfa7cc7e73318053c9a994b0178
法律聲明

FDS BIOS 的著作權屬於任天堂。請僅使用從您擁有的硬體中備份的 BIOS。AprNes 不包含此檔案。

3 放置 BIOS 檔案

在 AprNes.exe 所在的目錄中建立一個名為 FDSBIOS 的資料夾，並將 BIOS 檔案放入其中：

<AprNes.exe 所在位置>\FDSBIOS\DISKSYS.ROM

例如：

C:\Games\AprNes\AprNes.exe
C:\Games\AprNes\FDSBIOS\DISKSYS.ROM
注意

檔案名稱必須是 DISKSYS.ROM（Windows 下不區分大小寫）。資料夾名稱必須是 FDSBIOS。

4 載入 FDS 遊戲

開啟 AprNes，以載入一般 NES ROM 的方式載入 FDS ROM 檔案（副檔名通常為 .fds）。AprNes 會自動偵測 FDS 格式並載入 BIOS。

支援的 FDS 檔案格式：

  • 含標頭 — 以 FDS\x1A 開頭的檔案（標準 .fds 格式）
  • 無標頭（原始格式） — 檔案大小為 65,500 bytes 的整數倍的原始磁碟映像
自動換碟

多磁碟遊戲的換碟操作由 AprNes 自動處理。當遊戲提示翻面或換碟時，模擬器會透過 BIOS 偵測請求，自動插入正確的磁碟面。

5 確認安裝

最終資料夾結構應如下所示：

AprNes.exe
configure\
FDSBIOS\
  └── DISKSYS.ROM (8,192 bytes)
tools\
... (其他檔案)

如果 BIOS 檔案遺失或無效，AprNes 會在您嘗試載入 FDS 遊戲時顯示錯誤訊息，說明問題所在（找不到檔案、大小不正確等）。
