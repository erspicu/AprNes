AprNes — FFmpeg Setup Guide

Enable video & audio recording / FFmpeg 錄影錄音設定教學

1 Download FFmpeg

Visit the official FFmpeg download page:

https://www.ffmpeg.org/download.html

Under Windows, click "Windows builds from gyan.dev" or "BtbN GitHub Releases".

Download the shared build (recommended):

  • Look for: ffmpeg-master-latest-win64-gpl-shared.zip (or similar)
  • The shared version is smaller — it separates DLLs from executables

2 Extract the archive

Unzip the downloaded .zip file. You will see a folder structure like:

ffmpeg-master-latest-win64-gpl-shared/
  ├── LICENSE.txt
  ├── bin/
  │   ├── ffmpeg.exe
  │   ├── ffprobe.exe
  │   ├── ffplay.exe
  │   ├── avcodec-62.dll
  │   ├── avformat-62.dll
  │   ├── avutil-60.dll
  │   ├── ... (other .dll files)
  ├── doc/
  └── include/

The files we need are all inside the bin/ folder.

3 Copy to AprNes

Copy all files from the bin/ folder into:

<AprNes.exe location>\tools\ffmpeg\

For example, if AprNes.exe is at C:\Games\AprNes\, the target is:

C:\Games\AprNes\tools\ffmpeg\ffmpeg.exe
C:\Games\AprNes\tools\ffmpeg\avcodec-62.dll
C:\Games\AprNes\tools\ffmpeg\avformat-62.dll
... (all .exe and .dll files from bin/)

Complete file list to copy:

ffmpeg.exe ffprobe.exe ffplay.exe avcodec-62.dll avdevice-62.dll avfilter-11.dll avformat-62.dll avutil-60.dll swresample-6.dll swscale-9.dll
Note

Create the tools\ffmpeg\ folder if it doesn't exist. The DLL version numbers (e.g. -62, -60) may vary depending on the FFmpeg version you download — that's fine, just copy everything from bin/.

4 Done!

Restart AprNes. The recording feature is now available. AprNes will automatically detect ffmpeg.exe in the tools\ffmpeg\ folder and enable video & audio recording.

Verification

Final folder structure should look like:

AprNes.exe
configure\
tools\
  └── ffmpeg\
        ├── ffmpeg.exe
        ├── ffprobe.exe
        ├── ffplay.exe
        ├── avcodec-62.dll
        ├── avformat-62.dll

1 下載 FFmpeg

前往 FFmpeg 官方下載頁面：

https://www.ffmpeg.org/download.html

在 Windows 區塊中，點擊 "Windows builds from gyan.dev" 或 "BtbN GitHub Releases"。

下載 shared 版本（推薦）：

  • 檔名類似：ffmpeg-master-latest-win64-gpl-shared.zip
  • shared 版本較小，將 DLL 與執行檔分開封裝

2 解壓縮

將下載的 .zip 檔案解壓縮，會看到以下資料夾結構：

ffmpeg-master-latest-win64-gpl-shared/
  ├── LICENSE.txt
  ├── bin/
  │   ├── ffmpeg.exe
  │   ├── ffprobe.exe
  │   ├── ffplay.exe
  │   ├── avcodec-62.dll
  │   ├── avformat-62.dll
  │   ├── avutil-60.dll
  │   ├── ... (其他 .dll 檔案)
  ├── doc/
  └── include/

我們需要的檔案全部在 bin/ 資料夾內。

3 複製到 AprNes

將 bin/ 資料夾中的所有檔案複製到：

<AprNes.exe 所在位置>\tools\ffmpeg\

例如，如果 AprNes.exe 位於 C:\Games\AprNes\，目標路徑為：

C:\Games\AprNes\tools\ffmpeg\ffmpeg.exe
C:\Games\AprNes\tools\ffmpeg\avcodec-62.dll
C:\Games\AprNes\tools\ffmpeg\avformat-62.dll
... (bin/ 內的所有 .exe 和 .dll 檔案)

需要複製的完整檔案清單：

ffmpeg.exe ffprobe.exe ffplay.exe avcodec-62.dll avdevice-62.dll avfilter-11.dll avformat-62.dll avutil-60.dll swresample-6.dll swscale-9.dll
注意

如果 tools\ffmpeg\ 資料夾不存在，請手動建立。DLL 的版本號碼（例如 -62、-60）會隨 FFmpeg 版本不同而變化，這是正常的，只要把 bin/ 裡的所有檔案都複製過去即可。

4 完成！

重新啟動 AprNes，錄影功能即可使用。AprNes 會自動偵測 tools\ffmpeg\ 資料夾中的 ffmpeg.exe，並啟用影音錄製功能。

確認安裝
