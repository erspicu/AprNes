## 2. JIT Changes

| Metric | Previous | Current | Delta |

| Total JIT methods | 208 | 208 | 0 |

IL size 減少 545 bytes（21.6%），但 CPU exclusive 佔比不變 — 代表 sprite fetch 不是 PpuPhase4 的主要瓶頸，dot 1 的初始化 (SWAR fill) 和 dot 0-64 的 OAM clear 佔了更多時間。

### Inline 變化
- `PPU_CheckPAR`: 4→3（合併後只在偶數 phase 呼叫，少了 1 次 inline site）
- `FlipByte`: 2→1（合併後 phase 5/7 共用一處）
- `CIRAMAddr`: 16→13
- `PpuBusRead`: 15→12

這些下降是因為代碼合併減少了 call site 數量，不影響執行效率。
