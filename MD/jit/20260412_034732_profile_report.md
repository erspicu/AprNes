## 2. Changes Made

### Mode 0 Sample Catchup
- **Before**: channel output (5 multiplications + expansion loop) computed EVERY APU cycle
- **After**: only computed at sample rate boundary (~every 40 cycles)
- Saves ~97.5% of mixing computation in Mode 0

### setvolumes() Deferred
- **Before**: `setvolumes()` called every APU cycle (3 conditional computations)
- **After**: only called when length counters actually change:
  - `setlength()` (half frame)
  - `processLenCtrReloadNonHalf()` (non-half cycles with pending reload)
  - `apu_4015()` ($4015 write zeroing counters)

### Test Time Improvement
- Previous: 62.5-63.1s for 184 tests
- Current: **61.5s** (-1.6%)
